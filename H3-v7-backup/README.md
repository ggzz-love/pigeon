# MiniMax-H3 FL2VA v7 材料备份

本目录汇集平台上的 v7 启动材料、源码基线和验证证据，供整理初赛提交使用。它还不是经过全新环境重建验证的独立工程，不能仅凭本目录声称可离线复现。

## 内容

- `project/`：平台项目中 v7 九齿 MHA 验证入口及 FL2VA 生成入口，包含入口校验所需的两个原始 ZIP。
- `sources/`：2026-11-06 InfiniCore 和 InfiniLM 源码基线归档及其 SHA-256。它是上游快照，尚未证明与成功运行时的全部修改一致。
- `evidence/`：个人存储中 `nine-fl2va-direct-20261107-123705` 的生成日志、记录和视频，以及 `nine-mha-e2e-20261107-121549` 的验证结果。日志和 JSON 含平台个人目录路径，公开前需检查并处理。

## 已核对的记录

生成记录显示退出码为 0，设备 0 至 7 均有九齿 MHA 调用；视频为 768×928、124 帧、24 fps，H.264 视频和 32 kHz 双声道 AAC。模型入口日志中的端到端时间为 410.100 秒。视频 SHA-256 为 `3314c2fe3c7c99137db4d99a56ccf6d5170c1142eb2d4369839625bc7496c52c`，与记录一致。九齿验证结果记载 AOT、JIT 通过，真实调度测试 8 个设备、40 次成功调用。

这不等于完成空环境重建验证，也不单独证明官方视频相似度达标。报告中的 SSIM 应以实际官方比较结果文件为准。

## 运行依赖与未完成事项

脚本依赖赛事 scnet-dcu 镜像、8 张 gfx936 卡、共享模型，以及原账号 AFS 中已构建的 InfiniCore/InfiniLM、Python 环境、运行缓存和九齿验证产物。脚本中的 `IFAB_AFS_HOME` 及固定目录不是跨账号通用安装方法。

公开仓库提交前仍需归档和核对成功运行使用的 Core/LM 源码改动、构建过程和依赖，取得官方比较原始结果，并检查第三方许可与公开内容。不要把候选优化补丁或上游源码基线描述为已验证的最终构建。模型权重不在此备份中。

原平台项目完整 ZIP 位于下载目录 `编译后的项目 23_33_00.zip`，其中还包含多个诊断版本及未验证候选文件；本目录只挑选了与 v7 相关的材料。
